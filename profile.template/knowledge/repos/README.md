# Per-repo notes

One file per repo, named like the key in `../../config/projects.json` (e.g. `web-app.md`). Practical
knowledge only: install/setup, how to run locally, env vars, test logins and where to get them,
QA paths in the UI, test commands, gotchas, flaky tests. Grown from workers' `Learnings:`.
Architecture and branch roles live in `../domain.md`, not here.
